# 电影院设计方案（待确认）

本目录保留已确认的设计预览。正式影院现已接入小屋幕布、浏览器数据库、照片上传、音乐与统一备份；请从小屋进入查看实际实现。3D 造型与材质使用项目现有 Three.js；照片是现有相册示例中的离线占位插图。

## 已确定需求

- 点击小屋幕布进入独立页面，左上返回小屋；原幕布回忆继续保留在回忆盒子。
- 后排观影视角，绿色圆润软座、浅木墙板、奶油色幕布、两侧帘子与暖光，延续小屋画风。
- 固定视角，以幕布为主，不增加探索、入场任务或其他彩蛋流程。
- 进入后先显示第一张，点击播放后照片与音乐一起开始；照片每秒切换一次。转场采用快速横向过片、短暂遮挡和轻微颗粒；场景本身保持稳定。播放启动方式随本次设计图一并确认。
- 横竖照片完整展示、不裁切；空余区域柔和填边，只显示图片。
- 独立放映清单，多图上传、拖动调整顺序、删除和本地保存，加入统一备份。
- 支持上传一首本地音乐，点击播放后开始，可暂停及静音。预览中的音乐文件名只用于说明布局。
- 先看设计图并确认，再开发；无需用户提供模型、照片或音乐，首版使用占位照片。
