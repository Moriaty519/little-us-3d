# 相册 · 叠页时光手帐设计

状态：需求与视觉设计均已确认，开发于 2026-11-01 完成。实际网页、离线 HTML、完整源码和浏览器验证截图已更新；本目录保留原始静态设计稿。

## 已确认需求

- 相册使用独立页面，点击右侧“相册”按钮或墙上相框进入，提供“回到小屋”。原“相框”快捷入口改名，原有相框回忆保留在回忆盒子。
- 单张叠页手帐，当前故事页居中，后面露出其他页；翻页有纸张弯曲、背面与阴影。
- 一次故事对应一页，多图可延续到后面的页，按日期从早到晚排列，支持年月目录跳转。
- 混合模板：日常拼贴、旅行图文、纪念日等，同一本手帐使用多种版式。
- 填写日期、标题、文字，上传多图、选择模板，自动排版并可调整照片裁切。
- 相册与足迹地图独立，各自添加内容，不互相读取记录或关联城市。
- 相册在本机浏览器保存，并加入统一备份；初始占位内容标记为可移除的“模板示例”。

## 六种模板

1. 日常拼贴：1 张主图、2 张小图，拍立得、胶带、少量涂鸦。
2. 旅行图文：大图、正文和小图，保留阅读留白。
3. 纪念日：两张照片、一句心里话、柔和贴纸。
4. 胶片格子：一页最多 6 张，多图故事延续到下一页。
5. 一封短信：正文为主，附一张照片。
6. 一张大图：大幅照片与简短标题。

这里的槽位数量描述每个模板的单页布局，不限制一个故事只拥有这些照片；照片多时自动产生后续页，继续属于同一个故事。

## 交互说明

- 左边年月目录与底部页面总览用于快速跳转，主浏览始终遵循日期顺序。
- 实际版通过年月目录和页面总览跳转，后方露出的纸层用于表现叠页厚度；没有实现逐页彩签。
- 上一页／下一页、点击页边、键盘左右键用于翻页。手机开发时保留触摸滑动和简单按钮；以电脑版设计为先。
- 编辑通过表单完成，模板控制胶带、贴纸、字体和版式，不需要自由拖动所有装饰。
- 裁切仅决定照片在模板里的显示位置，保存原照片与裁切参数；已在网页中实现。
- 照片下方短注释、年份、页数、日期、正文都是设计示例；开发后随实际内容调整，不作为用户真实回忆。
- 模板示例是体验用内容，不计入用户的实际回忆；移除示例不会影响自己添加的记录。

## 制作与范围

使用 Pillow 按精确的中文排版绘制设计 PNG，所有图像为代码绘制的占位插图。未使用参考照片里的人脸或文字作为用户内容。`render_album_design.py` 只生成本目录的设计文件，不会实现或修改应用。

这批是静态视觉设计，翻页图展示目标中间状态，不代表已运行的 3D 动画。对应功能已实现，并更新离线 HTML 与源码包。实际截图见 `../../preview/album.jpg` 等文件；手机完成 390×844 布局模拟，真机性能尚未测试。
