# 足迹地图 · 已确认设计

状态：用户已确认“可以，按这版开发”，对应网页功能已完成。这里保留开发前的静态设计稿；实际运行截图在 `../preview/`。

## 已确认需求

- 点击小屋墙上的地图，在当前网页内进入独立地图页面，提供“回到小屋”。
- 中国地图是可旋转、缩放的立体沙盘，各省略微凸起。
- 城市级定位：输入或选择城市，在地图上自动标出位置。
- 记录一起去过的地方；同一城市可保存多条记录，每条有日期、多张图片和文字。
- 有记录的城市显示暖色发光标记，点击打开该城市的记录与详情。
- 先完成电脑版本，继续使用本机浏览器存储，支持编辑、删除、导入导出备份。

## 三张设计图

1. `01-map-home.png`：浅木色底板、鼠尾草绿省份、奶油色界面。右侧是城市列表，地图上的城市使用暖金色小灯表示足迹，底部是旋转／缩放控制。
2. `02-city-detail.png`：地图保留在左侧，选中城市标记增加光圈；右侧展开该城市的记录，显示日期、图片、文字及其他记录入口。照片支持点击放大、切换；记录按日期排序。
3. `03-add-record.png`：地点、日期、可选标题、多张图片、文字。选择城市后在地图上预览位置，保存后点亮城市。右侧面板内容可以滚动，照片可增加或移除。

设计稿使用本项目已有的真实中国地图轮廓，以代码绘制静态 PNG。城市、日期和文字均为示例，图片区域为绘制的占位示意，不是用户照片。

## 设计中的默认细节

- 时间按已确认的“日期”记录，暂不要求小时／分钟。
- 地点和日期必填，标题、照片、文字选填；可以先点亮城市，之后再补充。
- 城市搜索候选显示所属省级地区，避免同名城市造成误选。
- 没有记录时显示空白足迹状态，不预置示例回忆；删除某城市最后一条记录后，该城市标记熄灭。
- 点亮的是城市标记，省份保持柔和的底色。
- 足迹记录与已有物件回忆分别展示，统一支持备份，并兼容旧版小屋回忆。
- 地图标签、侧栏和表单保持可读的普通网页界面，沙盘使用真实 3D 几何。
