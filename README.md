# little us. · 小小的我们

温暖的微缩 3D 情侣回忆空间、中国足迹地图、叠页时光手帐和客厅投影。家具、地图边框和可弯曲的纸页由代码生成，使用随项目提供的 Three.js r160，不依赖在线服务、建模软件或远程素材。

Git 提交、构建产物和预览图规则见 [`GIT_WORKFLOW.md`](GIT_WORKFLOW.md)。当前界面只保留入口、阅读、编辑和视角操作，介绍性文案与重复说明已收起。三类编辑器统一使用页面内确认保护未保存草稿；保存与照片处理期间避免重复提交，导入前先处理草稿。小屋和地图只在画面变化时重新绘制，减少静止时的 GPU 工作。

## 鹦鹉带逛首页

开场进入首页后，原栖木上的 Lumi 会出现邀请卡片，文案是“我是lumi，欢迎来到雪海的小屋，让我带你参观一圈吧”，下方有“跟随参观”和“自由探索”两个按钮。点 Lumi 或“跟随参观”启动导览，“自由探索”收起邀请并恢复正常操作。导览依次飞到 **小木屋 → 照片墙 → 吉他 → 地图 → 幕布**，最后飞回原小木屋栖木。每站只保留功能介绍和“上一步 / 下一步”；第一站的上一步禁用。Lumi 回到小木屋后，“下一步”会变为“完成”，点完成结束导览，结束卡片也可返回幕布。飞行期间隐藏卡片，左上角始终可跳过：点击跳过时 Lumi 会从当前位置直接飞回小木屋，再结束导览；也可按 Escape 退出。已移除虚线边框和连线、卡片内的跳过与进入按钮。木屋本身不再打开回忆，其他家具保留实际入口。跳过返巢截图：`preview/bird-tour-skip-current.png`。

鹦鹉额头已去掉黄色，保留绿色渐变、柔和脸部和蓝绿尾巴。飞行时沿路径朝前，到达后原地转向镜头。导览期间暂停鹦鹉日常跳动与拖动视角，退出恢复原亲子层级、位置、朝向和大小；未修改回忆记录。重播开场会重置提示，完成后也可再点鹦鹉带逛。支持减少动态效果，网页与离线单文件共用同一实现。模块为 `src/bird-tour-flight.js`、`src/bird-tour.js`；最新截图为 `preview/bird-tour-photos.png` 与 `preview/bird-tour-mobile-screen.png`。

## 打开网页

- 推荐 Mac 双击 `启动小屋.command`，固定使用 `http://127.0.0.1:4173`。也可在项目目录运行 `python3 tools/serve.py --open`。需要 Python 3。
- 也可以直接双击 `little-us.html`，在 Chrome、Edge 或 Safari 中打开。这是包含全部代码的离线单文件。
- 本地服务仅监听本机，终端按 Control+C 即可关闭。首次使用无需安装 Node 或 npm。

浏览器需要支持 WebGL 并启用硬件加速。电脑优先，手机已有自适应布局和双指缩放；真实手机触摸体验和性能仍待确认。

## 开场的一封信

每次新打开或刷新网页，先看到奶油色背景上的鼠尾草绿信封。点击封蜡，上方白色三角先展开，再依次打开两侧和下部，收在里面的后墙先按立体书方式立起，后墙完成后左墙再立起，随后家具逐件展开。两面墙的展开时段不重叠，左墙铰链位置固定，仅在后侧墙角预留少量折叠余量；收尾时不再平移整面墙。信封外侧带有小花叶枝、爱心和细虚线边饰，配粉色爱心封蜡；装饰跟随各片折页展开，内侧仍保留干净的纸面。窗户、门、照片墙和幕布随所属墙面一起转动；小鸟屋向房间内部折叠。信封正向居中展示，外层旋转 180° 使三角区域朝上；开头无投影，里面的小屋朝向保持原样，画布覆盖整个屏幕。约 4.6 秒完成展开后，纸面淡出，同一个房间用 1.25 秒连续转场进入可交互首页，无需再次点击。文案采用“致我们 / 很高兴认识你 / 把喜欢的日子，收进我们的小屋”。

信封花纹与固定铰链的当前预览：`preview/opening-floral-envelope.png`、`preview/opening-floral-envelope-mobile.png`、`preview/opening-floral-fixed-wall.gif`。

信封展开和按钮都没有音效，也没有背景音乐。小屋左下角“重播开场”可以重新体验，返回相册和足迹不会自动重播。刷新或重新打开任何页面时，先显示信封；展开后始终进入可互动的小屋首页，不保留相册、地图或影院位置。Escape 可跳过，系统减少动态效果设置会省略动画。

开场使用原来的透视小屋渲染器和照片，进入时移动同一张画布并连续调整取景。纸面和房间处于同一 3D 场景，最终恢复原家具尺寸、位置和拾取 ID；没有房间整体缩放升起的替代动画。所有素材和动画由代码生成，离线单文件同样可用。构建加入脚本／样式内容版本，刷新会加载对应的新资源。

当前浏览器截图：`preview/opening-top-flap-current.jpg`、`preview/room-white-roses-current.jpg`、`preview/opening-top-flap-mobile.jpg`、`preview/room-white-roses-mobile.jpg`。`preview/opening-upper-first-current.gif` 记录真实网页从拆信自动进入首页的完整过程。旧 `opening-*.png` 保留为此前纸卡方案记录。折叠原理参考 [Georgia Tech 纸工程说明](https://paper.gatech.edu/kinetic-joy/physics-paper-engineering/)。

闭合纸片和折平墙面保持独立间隙。小屋相机近裁面调整为 0.5，地毯、幕布、照片墙和地图与背板保留间距及深度偏移，地面阴影置于木底座下方，避免旋转时表面重合闪动。茶几上的书已替换成斑驳灰色陶瓷花瓶，插着六朵叠层白玫瑰、黄心小雏菊和尤加利圆叶枝；花束用真实几何建模。细节见 `preview/white-rose-vase-detail.jpg`。此前修复记录保留在 `preview/pop-up-repaired.gif`。

## 小屋回忆

互动首页左墙的窗户与地图已互换：窗户靠后并与墙角留出间距，地图放在窗户与门之间。窗帘、地图边框和门框各有空隙；地图实体点击仍进入足迹，入口相机跟随地图的新位置。窗玻璃透明，墙体为真实窗洞；地图与独立页共用模型和不受灯光改变的印刷配色。当前首页截图：`preview/home-clear-window-current.png`。

拖动转动小屋，向下拖动可以转到正俯视，滚轮或底部按钮缩放，房屋图标重置视角。小屋使用近大远小的透视相机，拖动保持焦距和相机距离；窗口尺寸变化时重新取景并保留缩放比例。点击吉他进入独立 KTV；录音设备或茶几上的花瓶打开物件回忆。幕布进入同一间客厅的沙发观影视角；墙上照片墙和右侧“相册”按钮进入时光手帐，原有幕布和相框回忆仍在回忆盒子。右侧快捷按钮也可通过键盘打开。当前花瓶入口与录音台对齐截图：`preview/room-vase-entry-current.png`。

“添加回忆”可保存标题、日期、文字、关联物件和一张照片。支持 JPG/PNG/WebP，每个原文件最多 20 MB；照片自动压缩为最长边 1600 像素的 JPEG，透明区域转为米白背景。最新小屋回忆的照片显示在照片墙。小屋幕布显示放映清单的第一张照片；保存排序、替换或导入清单后同步更新，清单为空时幕布留白。点击幕布进入同一间客厅的放映画面。回忆盒子支持浏览、编辑和删除。

后墙采用浅木色边框、鼠尾草绿洞洞板和六张夹住的拍立得照片，板上有真实凹孔。洞洞板右上角伸出一块小木搁板，手帐靠立在搁板上；木搁板、支撑和手帐一起缩为原方案的一半，原右上照片移到下方。它与阅读页使用同一张封面，照片和年份随自己的相册故事更新。最新六张小屋回忆照片会替换板上的插图；没有照片的位置保留设计插图。点击洞洞板或右侧“相册”进入手帐，继续使用原 photos 关联 ID。初始插图是代码绘制的占位装饰，没有预置情侣回忆。当前细节及转场：`preview/pegboard-journal-upper-right.png`、`preview/pegboard-album-transition.gif`。

## 我们的足迹地图

相册、足迹、影院与 KTV 从小屋的洞洞板手帐、中国地图、幕布和吉他进入。足迹入口先准备并恢复地图初始大小，再像影院幕布一样等页面就绪，用约 1.08 秒平滑对准地图页的真实位置和大小，随后约 0.14 秒完成同一视点的镜头衔接，最后约 0.4 秒只淡入地图页、不缩放整页；交接时地图位置、大小和印刷颜色保持连续。相册使用专门的衔接：约 0.96 秒对准搁板上的手帐封面，并匹配阅读页封面的屏幕位置和大小；随后约 0.72 秒淡出房间，只保留书本，再接上阅读封面；最后约 0.2 秒显示目录和底部按钮。每次从小屋进入相册先显示闭合封面。返回小屋恢复进入前的旋转和缩放。转场中暂时锁定页面操作，Escape 或浏览器返回可取消；系统减少动态效果设置会直接进入。实际转场预览：`preview/map-aligned-transition.gif`、`preview/pegboard-album-transition.gif`、`preview/feature-cinema-transition.gif`。

点击小屋墙上的中国地图，或右侧“足迹”按钮，进入独立地图页面。左上角“回到小屋”返回原房间。

独立页复用小屋的木框地图和鼠尾草绿墙板，移除窗户和窗洞，以连续背景墙突出地图。进入地图页时是一幅正视挂在墙上的地图，初始视角垂直于地面，不再常驻右侧大卡片；右上角保留一个很小的“足迹”按钮，点开后是城市列表、详情和添加／编辑抽屉。地图印刷面使用同一纹理和配色，浅黄色背板不显示网格线；木框与内背板按可互动首页的光照校准，进入前后保持同样的木色。真实木框、墙板与城市针仍为 3D 几何。地图支持鼠标左键或单指直接拖动平移，短按仍会选中城市或点击空白返回总览；滚轮、底部按钮或双指可缩放，拖动只平移、不会旋转。每次从首页进入地图页都恢复初始大小和位置。中间按钮重置缩放与平移，调整窗口大小保留当前缩放比例。当前截图：`preview/qingdao-map-wall-current.png`、`preview/qingdao-drawer-current.png`。

点击地图上的青岛，或抽屉里的“青岛 · 微缩场景”，页面文字和 UI 先淡出，镜头用约 1.7 秒推近青岛，随后地图放平并淡出，切到独立的蓝绿色海面场景。新青岛模型来自 `地图/青岛/qingdao.html`：一座完整的小岛，包含圣弥厄尔教堂、青岛啤酒、Q 版小游艇、沙滩礁石和会流动的海浪。小岛放在一块与地图纸面同色系的黄白色圆形纯色平板上（不显示地图内容）。入场完整播放约 5 秒构建动画：海水、底座和岛屿沙滩先出现（沙滩水下部分也从第一帧显示），随后 5 颗礁石、贝壳、冲浪板、游艇、教堂和啤酒依次从海面落位；构建完成后才能操作，不能点击跳过。海水没有侧壁：原有水面范围扩大并收在圆形底座边缘内，水面从中心向四周逐渐降低，到边缘高度归零；海浪和水面法线持续流动，点击水面会从落点扩散出小范围、边缘规则的涟漪；扩散到最大时已经淡出。游艇保留完整船体；礁石只裁掉沙滩底面以下的部分，水面以下、沙滩面以上的礁石和游艇船体都会保留，构建结束时也不会再把水下部件的裁切面打开。完成后可拖动旋转、滚轮或双指缩放，没有自动旋转和视角按钮；左上角保留“返回地图”，Escape 也可返回，返回时小岛淡出、地图从放平状态立回墙上。当前青岛截图：`preview/qingdao-island-current.png`、`preview/qingdao-island-build-current.png`、`preview/qingdao-island-ripple-current.png`、`preview/qingdao-island-mobile-current.png`。

如果后续要继续添加其他城市，可以以青岛为模板，在 `qingdao-island.js` 中增加模型和解码逻辑（模型数据放在 `qingdao-model.js`），并把城市 id 接入 `travel-scene.js` 的聚焦入口；地图投影和抽屉逻辑不需要重写。GLB 仍以 base64 内嵌，保证离线单文件可用。

地名按屏幕空间自动避让其他标签、城市针和 UI，偏移的标签用短细线连接真实地点。密集区域暂时收起部分地名，保留全部城市针；放大后重新安排并显示更多地名。鼠标移近城市针、从列表选中城市或新增预览时，该城市优先显示；悬停和键盘聚焦的标签保持位置，避免点击时跳动。城市针的点击范围稍扩大，视觉大小保持原样。密集城市预览仅为测试页面，不向本地记录写入示例。

1. 点击“添加足迹”，输入城市名，并从候选列表选择城市。选择后在地图上预览位置。
2. 填写日期，可选填标题、文字和多张照片。城市与日期必填；标题最多 60 字，文字最多 4000 字，每条最多 12 张照片。照片类型、20 MB 原图限制和压缩方式与小屋相同。
3. 保存后，城市亮起暖金色小灯。点击小灯、城市标签或右侧列表直接进入该城市详情，默认显示最近一次同行，可切换同城其他记录。右上角“返回总览”或点击地图上的非城市空白处回到总览；也可直接点击其他城市切换详情。拖动、双指缩放不会触发空白返回；编辑表单时点击空白不会离开或丢失草稿。
4. 点击照片放大，用左右按钮或方向键切换。记录支持编辑和删除；删除城市最后一条记录后，小灯熄灭。删除前有确认窗口。

内置 378 个离线地点，覆盖 34 个省级地区，主要为地级城市、自治州和地区，也包括直辖市、部分直管市县及台湾常用城市。当前不支持所有县级市、具体景点或街道地址；标记使用城市中心坐标。台湾常用城市坐标为手工整理，其余主要来自 DataV。可以继续补充 `src/cities.js`。

足迹最多保存 2000 段，照片也受浏览器剩余空间限制。足迹与物件回忆分别展示，足迹照片不会覆盖小屋照片墙或幕布。空白页面不预置示例记录。

## 我们的时光手帐

独立阅读页的封面和内页主体比此前放大约 15%，年月目录向上收紧；翻页按钮稍大，并根据书本实时投影的下沿排布，封面展开或合拢时同步移动。编辑与删除操作靠近翻页区，手机保留足够点击空间。小屋转场读取这一页实际封面的大小和位置，对准新的阅读尺寸后再淡出房间。当前预览：`preview/album-enlarged-cover.png`、`preview/album-enlarged-spread.png`、`preview/album-enlarged-mobile-cover.png`。

点击小屋墙上照片墙或右侧“相册”，进入独立相册页；左上角“小屋”返回房间。封面是居中的单面竖版书本，使用底部“下一页”按钮展开，第一页使用“上一页”按钮可重新合拢。当前故事是一张中央对折的真实 3D 纸面，左右两半铺满同一个故事；已翻过和待阅读的纸页分别向左右展开。逐页翻阅使用底部 UI 按钮，单侧纸页沿中缝弯曲翻动，正反面显示相应故事内容。书本上的照片只支持点击放大查看；拖动书页、点击封面、空白页边或露出的相邻纸层不会翻页。按日期从早到晚排列，照片或文字多时自动续页；页码按整张折页计数，左右两半不分别计页。点击月份会根据目标页方向快速连翻多张纸页，停在该月份的第一页；目录“封面”也使用同样的动画合拢书本。连翻纸页错开启动、同时弯曲，远距离跳转最多显示七张代表纸页，动画约 0.4—1 秒；系统减少动态效果时直接切换。动画结束后同步页码和月份，过程中避免重复跳转，离开或打开编辑器会停止动画。页面总览仍可直接跳转。大图弹窗中可使用按钮或左右方向键切换同一故事里的照片。

1. 点击“写一页”，填写日期，可选填写标题和文字，上传多张照片。编辑器仅保留一个显示当前模板的按钮；打开预览后直接点击卡片选择，自动更新当前草稿。
2. 选择一张大图、纪念日、一封短信或日常拼接，实时预览自动排版。模板容量不同，多图仍属于同一个故事。
3. 点“调整裁切”，拖动或用方向键调整位置，用滑块缩放，再应用。原照片保留，保存裁切参数；箭头按钮可以调整照片顺序。
4. 保存后可以重新编辑或删除整个故事。离开未保存的相册编辑时有页面内确认。

四种可选模板均避开中间折痕；一张大图在右半放竖幅大图、左半放标题与文字。旧版旅行图文和胶片格子故事仍可展示、导入，编辑时默认保留原模板，也可主动转换到现有模板，保留全部照片和文字。每个故事最多 24 张照片、60 字标题、4000 字正文，最多保存 1000 个故事。故事需要至少包含标题、文字或照片之一。照片压缩和原图限制与小屋相同，最终可保存数量取决于浏览器剩余空间。空余照片槽位保持留白；封面优先使用自己故事的照片。纸页只绘制当前位置附近的少量内容，跳转很远的日期时不会加载中间所有页。

初始四页为模板示例，使用离线绘制的占位插图。右上角“···”提供页面总览、移除或恢复示例、导出及导入备份；示例开关在本机保存。示例不计入自己的故事，也不进入备份。相册与足迹各自添加内容；相册照片不会替换小屋幕布或照片墙的旧回忆照片。

## 客厅投影

影院入口先准备场景及第一张照片，再用约 1.08 秒平滑移动镜头；终点与观影页共用镜头位置、方向和视野，幕布及周围家具在交接时保持大小和位置。随后约 0.4 秒叠入观影画面，保留小屋作为不透明底层，避免淡入中变暗；按钮稍后出现，页面不再整体缩放。幕布镜头移动时取消原约 30 帧的渲染限制。动画：`preview/cinema-smooth-entry-current.gif`。

点击小屋幕布或右侧“幕布”进入 `#cinema` 观影页面，左上“小屋”返回。直接复用首页的 `createRoom` 建模，观影镜头朝向后墙幕布；家具、墙面、地图位置、照片墙和手帐封面与首页同步。进入时先显示第一张，点击播放后每秒切换一次；两张照片间用干净的横向过片和细窄接缝衔接，不再出现上下胶片孔或胶片边框；下一张向左推进，上一张反向返回。暂停按钮在换片过程中也始终可点。横竖照片保留完整比例，空余区域柔和填边，幕布只显示图片。暂停、上一张、下一张、照片小点和左右方向键可用；场景横向滑动可切换，切到后台或离开页面会暂停照片及音乐。

“放映清单”支持多张照片上传、拖动排序、删除、保存及取消。直接拖动照片到目标照片上，两张照片互换位置，其他照片保持原位，拖到列表上／下边缘会自动滚动；松手在列表外或按 Escape 可取消拖动。也可聚焦照片后按方向键与对应照片互换，Home／End 与第一张／最后一张互换。初始六张为离线占位插图；上传自己的照片后替换占位图，占位图可移除或恢复。照片处理方式与小屋一致，最多 60 张。保存后刷新可恢复，未保存修改有页面内确认。

可上传一首 MP3、M4A、WAV 或 OGG 本地音乐，原文件最多 30 MB；保存后点击播放，音乐循环播放，可静音、替换或移除。没有预置背景音乐。影院照片和音乐独立于相册、足迹及物件回忆，加入统一备份，不自动共享或同步。手机保留同一个观影位置，调整镜头可视范围，让幕布完整显示并避开操作栏。每次重新进入都从第一张开始，退出不会改变首页视角。幕布保持正对与水平居中，画面略高于页面中心：上移页面高度的 3%，最多 24 像素；取景大小不变，入口转场同步使用同一偏移。

## 吉他与我们的 KTV

点击小屋中的吉他实体或“吉他”快捷按钮进入 `#ktv`。先用原小屋相机拉近吉他，按目标页面的真实投影匹配主体的位置、尺寸与朝向；原房间淡出后，同一款吉他留在 KTV，再用约 1.12 秒拉开镜头展示整个包间。吉他共用同一份曲面、音孔、琴颈、品丝与六根琴弦，交接不会更换外形。系统减少动态效果时直接展示包间；Escape 或浏览器返回可在任何阶段取消，返回恢复原小屋的旋转与缩放。

KTV 是代码建模的完整三维微缩包间，延续奶油色、鼠尾草绿与浅木色：软包吸音墙、拼木地板、地毯、圆角茶几、加宽并右移正对屏幕的沙发、双手持话筒、音箱、设备柜和视频大屏。左侧靠墙的长舞台只在靠近大屏的一端放立麦，其余舞台留空；两盏吊灯换成左墙一排五色射灯，灯头进一步向下倾斜，但聚光灯的位置、目标和光束保持不变。电视柜上的机顶盒已居中并贴着柜面，不再错位。顶部只保留“小屋”、一个“上传视频”、灯光及备份菜单。

“上传视频”打开同一面板，面板里只有一个文件入口，接受 MP4 / WebM / OGG / MOV 本地视频。照片轮播、照片放大、上一张／下一张、音乐列表和播放音乐逻辑均已移除，不再有上传音乐或播放音乐的入口。视频存入本机 IndexedDB 的 `ktv-playlist`，不覆盖原幕布清单；文件越大保存越慢，浏览器空间不足时会提示先导出备份并整理视频。旧版 KTV 备份仍可导入，原来的照片和音乐会被视为空视频房间，不会导致导入失败。

大屏默认显示视频首帧。点击大屏后，镜头用约 1 秒平滑推进到正对屏幕的视角，取景方式与客厅幕布的正面观影一致；底部出现播放 / 暂停、时间和静音按钮。进入正面视角后不会自动播放，按播放才开始；返回包间会暂停视频。部分浏览器可能拦截声音自动播放，此时再按一次播放即可。正面视角中按 Space 播放 / 暂停，Escape 返回包间。点击吉他仍可拨弦，按 C → Am → F → G 轮换；音色采用柔化起音、滤除尖锐高频的木吉他合成。灯泡切换暖灯／晚霞，拖动旋转包间，滚轮和底部按钮缩放，拖动不会切换视频。

切换后台或离开 KTV 会暂停视频。真实浏览器预览见 `preview/ktv-current.png`、`preview/ktv-mobile-current.png`；`preview/guitar-ktv-transition.gif` 保留初版转场记录。

## 本地保存与备份

所有记录保存在当前浏览器的 IndexedDB，不发送给服务器。相册、地图、影院、KTV 和回忆盒子的导出按钮都生成统一 v6 JSON 备份，包含小屋回忆、足迹、相册、照片及裁切参数，以及影院照片和音乐、KTV 的单个视频。导入支持 v6、v5 KTV 旧版照片／音乐备份、v4 影院备份、v3 相册备份、v2 足迹备份与旧版 v1 小屋备份；记录按 ID 去重并保留更新时间较新的内容，影院与 KTV 分别保留更新时间较新的整份清单。旧版备份不会清除现有足迹、相册、影院或 KTV。导入先校验全部数据、照片、视频和音乐，再在单个事务中写入。单个导入文件上限 150 MB。

数据库继续使用原来的 `little-us-memories-v1` 名称和版本 3，保留 `memories`、`journeys`、`albums` 和 `settings` 表。影院与 KTV 清单存入现有 `settings` 表，不再升级数据库。如出现升级受阻提示，请关闭其他旧版小屋窗口后刷新。

**请定期导出备份。** 不同浏览器、端口、地址及直接打开的文件拥有不同存储空间；改变打开方式前先导出，再导入。清理浏览器数据、隐私模式、移动 HTML 文件都可能使回忆不可用。备份包含照片、视频和文字，请妥善保管。目前不会自动与伴侣或其他设备同步。
